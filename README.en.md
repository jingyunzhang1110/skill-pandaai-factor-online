# factors_lab Factor Mining Skill

A pure factor-mining Skill for `jingyunzhang1110/factors_lab`.

The Skill now emits the **exact JSON schema consumed by factors_lab `common_factor import-factors`**. There is no candidate-to-import manual conversion step.

Guarantees:

- strict whitelist of factors_lab canonical features;
- exact current AST kinds/operators/parameter rules;
- no future inputs or negative lags;
- rejection of unknown AST keys and static size/lookback violations;
- known-dimension consistency checks;
- exact/rank-equivalent mother-bank and in-batch deduplication;
- rejection of parameter-only variants and zero-mask conditionals;
- no formal 16-digit factor IDs generated by the Skill.

Generate a batch following `examples/new_factor_batch.example.json`, then validate:

```bash
python scripts/validate_candidates.py \
  --input generated_batch.json \
  --output ready_for_factors_lab.json \
  --report audit_report.json
```

The resulting `ready_for_factors_lab.json` can be handed directly to factors_lab:

```powershell
python .\common_factor\top.py import-factors .\ready_for_factors_lab.json
```

factors_lab then owns fingerprinting, historical RAW deduplication, ID allocation, append-only RAW shard creation, Registry bootstrap, single-factor screening and multi-factor research.
